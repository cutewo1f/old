## ✦ Overview

Remember the old Discord UI?

**old.** is a custom Discord theme that aims to bring back the familiar look and feel of classic Discord, taking inspiration from its older interface while retaining compatibility with the modern client.

Built with CSS and powered by [Vencord](https://github.com/Vendicated/Vencord).

## ✦ Features

- Classic-inspired Discord interface
- Restored colors and familiar UI elements
- Custom CSS adjustments and refinements
- OldCord component integration
- Designed for Vencord's QuickCSS

## ✦ Installation

### Requirements

- [Discord](https://discord.com/)
- [Vencord](https://vencord.dev/)

### Method 1 — QuickCSS (Recommended)

1. Open Discord.
2. Navigate to **Settings → Vencord → QuickCSS**.
3. Paste the following line at the very top of your QuickCSS editor:

```css
@import url("https://raw.githubusercontent.com/cutewo1f/old/main/main.css");
```

4. Save your changes.
5. Enjoy the classic Discord experience!

### Method 2 — Manual Installation

1. Download [`main.css`](https://github.com/cutewo1f/old/blob/main/main.css).
2. Open Discord and navigate to **Settings → Vencord → Themes**.
3. Click **Open QuickCSS File** or open your QuickCSS editor.
4. Copy and paste the contents of `main.css`.
5. Save and restart Discord if necessary.
